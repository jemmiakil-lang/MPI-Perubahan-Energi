# Energi Explorer — MPI Online IPAS Kelas IV

Paket situs statis interaktif untuk topik perubahan energi dan macam-macam gaya, disesuaikan untuk peserta didik kelas IV SD.

## Isi paket
- `index.html` — aplikasi web lengkap, termasuk HTML, CSS, dan JavaScript.
- `PANDUAN_PUBLIKASI.md` — petunjuk publikasi ke hosting statis.

## Uji coba lokal
1. Ekstrak ZIP.
2. Buka folder `MPI_Perubahan_Energi_Online`.
3. Buka `index.html` menggunakan Chrome, Edge, Firefox, atau browser modern lainnya.

Tidak perlu instalasi atau koneksi internet untuk membuka file lokal. Setelah dipublikasikan, MPI dapat diakses lewat tautan web.

## Catatan
- ZIP ini siap diunggah, tetapi belum otomatis dipublikasikan ke internet.
- Kuis dihitung di browser. Nilai tidak dikirim ke guru dan tidak disimpan di server.
- Tidak ada akun siswa atau pelacakan aktivitas.
